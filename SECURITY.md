# Security policy

## Report a vulnerability

Report a vulnerability in the operator console or in `@beaconsgg/admin-plugin` through GitHub's
private vulnerability reporting. Open the repository's **Security** tab and choose **Report a
vulnerability**. Only you and the maintainers can see the report.

If you can't use GitHub, email `security@beacons.gg`. Send reports about the hosted service at
`console.beacons.gg` or `beacons.gg` to the same address.

Don't open a public issue, pull request or discussion about a vulnerability.

A report helps most when it includes:

- the affected version of the console image or of `@beaconsgg/admin-plugin`;
- the steps that reproduce the problem;
- what an attacker can do with the problem.

## What to expect

The maintainers acknowledge a report within 3 business days.

## Supported versions

Only the latest release of the console and of `@beaconsgg/admin-plugin` receives security fixes.
